# Social Media Analytics Project (Instagram Clone)

A comprehensive data analytics project analyzing user engagement, activity patterns, and database metrics on an Instagram clone (`ig_clone`) database.

## 📁 Repository Contents

- **`social_media_template.sql`**: SQL scripts covering objective and subjective analytical questions on user behavior, comments, likes, tags, and follower networks.
- **`Project_Tasks_of_Social_Media.docx`**: Detailed problem statement, business task definitions, and assignment requirements.
- **`SOCIAL_MEDIA_BY_PRANAY.pptx`**: Project presentation covering key findings, data visualizations, and strategic insights.

## 🛠️ Key SQL Analyses

- **Data Integrity**: Auditing null values and duplicate records across `users`, `photos`, `comments`, and `follows`.
- **User Activity Metrics**: Distribution of posts, likes, and comments across active vs. inactive users.
- **Content Engagement**: Average tags per photo and identifying top trending hashtags.
- **Network Analysis**: Follower-to-following ratios and bot/ghost account detection.

## 🚀 Getting Started

1. Import the `ig_clone` database schema into your MySQL/SQL environment.
2. Execute the queries in `social_media_template.sql` sequentially to reproduce the analysis.
